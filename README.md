# Redeem Technical Services

Website for Redeem Technical Services, a Zambian general contractor and supplier serving mining, construction, engineering, transport, equipment, industrial supplies and labour hire requirements.

## Pages

- `index.html` - company homepage
- `services.html` - technical, mining, construction and supply services
- `equipment-hire.html` - excavator, dump truck, tipper truck and related equipment hire
- `approach.html` - service standards and working process
- `company.html` - company overview and management team
- `contact.html` - Kitwe and Lusaka offices and enquiry form

## Images

The site uses `photos/placeholder.svg` as a temporary image. Replace it with company or equipment images when they are available. The `photos/README.txt` file contains suggestions for image filenames.

No company logo has been added.

## Local Preview

Open `index.html` directly in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The enquiry form currently demonstrates front-end validation and confirmation. Connect it to a secure backend or form service before production use.
